# Documentación de PhDexLab

Esta documentación describe el funcionamiento actual de la aplicación, tomando **0.9.1** como versión de referencia. La descarga vigente siempre está en [Releases / latest](https://github.com/RpastranaE/PhDexLab/releases/latest).

- **Primera vez:** [Manual de uso](MANUAL.md), desde instalación hasta resultados.
- **Quiero cambiar el programa:** [Desarrollo y compilación](DEVELOPMENT.md), desde descargar el código hasta probar y empaquetar cambios.
- **Quiero comprobar el fundamento:** [Fuentes de protocolos](PROTOCOL_SOURCES.md) y [validación del software](VALIDATION.md).
- **Busco información de otra versión:** [Historial de cambios](../CHANGELOG.md) y [archivo histórico](archive/README.md).

El manual es la referencia para el uso; desarrollo explica la implementación y las herramientas. La validación registra evidencias, no instrucciones alternativas. Las notas de versión cuentan novedades, no sustituyen al manual.
